Fixes the self-hosted Docker server failing to start on Synology NAS and other hosts with older Linux kernels.

## Fixes

- The Docker image now starts on hosts running Linux kernels older than 4.11, such as Synology DSM. Previously the server exited at startup with `Cannot find module '@sentry/node'`. (#152)

## Everyday improvements

- The Docker image is about half the size, because it now ships only the server's production dependencies.

## Upgrade notes

- Self-hosted installations: pull `ghcr.io/will-be-done/will-be-done:0.13.1` (or `latest`) and recreate the container. No data migration is needed.
- The web client, sync protocol, and v1 API are unchanged from v0.13.0. Desktop builds are republished with the new version number only, so updating them is optional.
