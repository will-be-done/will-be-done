## What's changed

- Added Flatpak support for Linux.
- Improved the Linux desktop experience with a system tray. Closing the main window now keeps the app running, with options to reopen it, use Quick Add, or quit.
- Improved Global Quick Add on Wayland, including compositor shortcuts and a new `--show-quick-add` command-line option.
- Improved Quick Add window focus and reliability on Linux.
- Fixed a Firefox crash and improved initial task data loading.
- The desktop app now connects to the hosted Will Be Done service by default in production.
